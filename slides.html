THE PROBLEM

Housing search is fragmented for new arrivals.

An international student may need to compare floorplans and rents near SOM, verify availability and concessions, understand an unfamiliar lease, and plan move-in.

Understand

Which dates, costs, utilities, and responsibilities are actually stated?

Clarify

What is missing—and what should I ask before arrival?

Prepare

What should happen before the keys are handed over?

Yale already provides the Off-Campus Marketplace. FirstLease adds a SOM-centered comparison, transparent source dates, a listing-grounded chatbot, then lease and move-in support.

WHAT IS DIFFERENT

One path from housing search to move-in.

Lease fact

“Monthly rent is $1,450…”

Question

“What time can I pick up the keys?”

Move-in task

“Photograph existing damage and share the record.”

Product hypothesis: pairing source text with missing-item questions and dated reminders makes the renting handoff easier. It must be validated with renters.
HOW THE AGENT WORKS

Two local tools bound one reviewer.

Lease text is untrusted. Local tools return candidate excerpts and reminders; the reviewer structures the result. The user verifies the original document.
